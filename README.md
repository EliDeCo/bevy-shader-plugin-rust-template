# bevy-shader-plugin-rust-template

A minimal Bevy app with a fullscreen fragment shader written in Rust, using
[bevy-shader-plugin](https://github.com/EliDeCo/Bevy-Shader-Plugin) and
[rust-gpu](https://github.com/Rust-GPU/rust-gpu). Clone it and run it; the shader is compiled
automatically.

| bevy-shader-plugin | Bevy | rust-gpu |
|---|---|---|
| 0.2 | 0.19 | 0.10.0 |

## Requirements

- [rustup](https://rustup.rs). The pinned nightly toolchain in `rust-toolchain.toml` is installed
  automatically on the first build. If it isn't, run
  `rustup toolchain install nightly-2026-07-03 --component rust-src,rustc-dev,llvm-tools`.
- Vulkan, Metal or DX12. rust-gpu shaders don't work on the web.

## Running

```sh
cargo run
```

The first build compiles the rust-gpu compiler and takes several minutes. Later builds take
seconds. Edit `shader/src/lib.rs` and `cargo run` again; `build.rs` recompiles the shader whenever
its source changes.

## Layout

```
rust-toolchain.toml   the nightly rust-gpu needs; applies to the whole project
Cargo.toml            the app, plus spirv-builder as a build-dependency
build.rs              compiles shader/ and copies it to assets/shaders/shader.spv
src/main.rs           the app
shader/src/lib.rs     the shader
```

`assets/shaders/shader.spv` is generated by every build and is ignored by git.

## Writing shaders

The app registers buffers with the plugin, and the shader declares them with matching indices:
`descriptor_set` is the group index and `binding` is the binding index.

| app (`src/main.rs`) | shader (`shader/src/lib.rs`) |
|---|---|
| `register_uniform_buffer::<Globals>(0, 0)` | `#[spirv(uniform, descriptor_set = 0, binding = 0)] globals: &Globals` |

- **Access mode.** `&` is read-only and `&mut` is `read_write`, and every entry point that uses a
  binding must match how it was registered. GPU buffers and `read_write` storage buffers must be
  taken as `&mut` everywhere, even in entry points that only read them.
- **Entry points** are named after their functions. The fragment entry point is passed to
  `with_entry_point`. Compute passes name theirs in `ComputeShaderPlugin::pass`.
- **Buffer layout.** Mark shared structs `#[repr(C)]` and keep the Rust and shader definitions
  identical. Stick to `Vec2`, `Vec4`, `f32`, `u32` and arrays of them, and avoid `Vec3`. Keep arrays
  out of uniform buffers unless the element is 16 bytes; use a storage buffer instead.

The [plugin's README](https://github.com/EliDeCo/Bevy-Shader-Plugin#readme) covers every buffer
type, compute shaders and readback.

## Examples

The plugin's [`examples/`](https://github.com/EliDeCo/Bevy-Shader-Plugin/tree/master/examples) have
Rust versions that drop straight in. Copy an example's `rust/app.rs` over `src/main.rs` and its
`rust/shader.rs` over `shader/src/lib.rs`, then `cargo run`.
